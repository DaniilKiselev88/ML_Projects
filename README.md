ML-проекты (Jupyter Notebook)

Реализовал пайплайн предобработки данных для датасета Titanic (пропуски, масштабирование, one-hot encoding).

Сравнил эффективность Logistic Regression и Random Forest (точность 77.5% vs 79.8%).

Проанализировал важность признаков (feature importance) и выявил ключевые факторы выживания.

Также реализовал примеры линейной и полиномиальной регрессии с оценкой метрик (MSE, R², RMSE) на реальных данных (Boston Housing).
